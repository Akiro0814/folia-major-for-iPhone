# iOS 实施与验证记录

更新：2026-10-18。构建仓库当前地址为 `Akiro0814/folia-major-for-iPhone`，原 `L1angK1NG` 地址仍重定向到同一仓库（repository ID `1421872609`，账号 ID `221821878`）。Bundle identifier 保持不变，避免账号更名改变应用身份。

## 已落地的产品代码

- SwiftUI iOS 26+ 导航、系统液态玻璃、原生横竖屏与全屏歌词。
- 原生 AVPlayer、后台音频、锁屏封面和系统命令、队列、音质、循环随机、睡眠定时、恢复时保持暂停。
- 网易云、酷狗、QQ、波点、Navidrome 经统一 Omni 契约接入，包含实际协议支持的搜索、账户、歌单、推荐、专辑和歌手目录。
- 网易云／酷狗验证码、密码与扫码；QQ／微信扫码；波点扫码；Navidrome 自有服务器账号。登录态存 Keychain，取消或替换登录不会恢复旧请求。
- 内置原项目 14 种歌词模式、背景与解析器；原生 KRC／QRC 解密；LRC、YRC、QRC、KRC、TTML、AWLRC 传入复用渲染层。
- 原生视觉调参清单由上游默认值生成，支持嵌套参数；四配色编辑、主题库、AI 配色、外观同步和应用备份。
- 非破坏性 PCM 音频采样、RMS 和五段 FFT 分析接入歌词桥；受保护流、HLS 或不支持的 PCM 格式明确回退为不可用。
- Navidrome 封面持久化为不含鉴权的引用，显示时才临时解析；原生图片请求和 WebKit 使用不持久化会话。

以上是代码范围，不等于所有平台已完成真实账号或签名设备验收。更细的保留、平台限制与缺失能力见 `docs/ios-feature-matrix.md`。

## IPA 交付门槛

必须先取得成功的原生测试和真实 iPhoneOS Release 构建，再校验 `Payload/Folia.app`、arm64 Mach-O、最低系统版本、歌词资源与 SHA-256。未签名 IPA 仍需用户签名安装。真实平台授权、会员歌曲、后台／蓝牙／AirPlay、电话中断和系统旋转锁定由已签名真机验证，不能用模拟器替代。
